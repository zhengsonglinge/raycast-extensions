# 注意事项

- DeepSeek API Key 使用 Raycast password preference 保存，不要写入源码、README 或提交记录。
- 在 `Ask DeepSeek` 命令里可以通过 `Edit DeepSeek API Key` action 或 `Cmd+,` 打开扩展设置修改 API Key。
- 模型可以在命令搜索框右侧的 dropdown 里切换，默认值来自 Raycast 扩展偏好设置。
- 会话历史保存在 Raycast LocalStorage 中，最多保留最近 20 条；默认页面不展示历史，可以通过 `Show History` action 或 `Cmd+Y` 打开历史页，再通过 `Clear History` action 清空。
- 回答会在全宽结果页展示，不使用列表右侧详情分栏；结果页中选中文本后使用系统 `Cmd+C` 复制选中内容，复制整段回答使用 `Copy Answer` action 或 `Cmd+Shift+C`。
- 如果请求失败，先检查 Raycast 扩展偏好设置里的 API Key 是否正确，再检查 DeepSeek 账户余额和接口额度。
- `deepseek-reasoner` 可能返回 `reasoning_content`，扩展会把推理内容和最终回答一起展示在详情里。
- Temperature 只接受 `0` 到 `2`，避免把非法值传给接口。
