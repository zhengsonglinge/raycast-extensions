# Unicode Encoder 功能说明

## 功能目标

在 Raycast 中输入任意字符串，立即得到对应的 Unicode 编码结果，便于开发、调试和文案排查。

## 当前交互方式

- `Unicode Encoder`
- 直接在 Raycast 搜索栏输入文本
- 右侧详情面板实时展示完整结果
- 通过动作面板复制所需输出

## 当前输出

- Unicode Code Point，例如 `U+0041 U+4F60 U+597D`
- JavaScript Unicode Escape，例如 `\u0041\u4F60\u597D`
- 按字符映射结果，便于逐个核对字符与编码

## 使用方式

1. 在 Raycast 中执行 `Unicode Encoder`
2. 输入字符串
3. 在右侧查看完整结果并复制所需输出

## 适用场景

- 前端源码中的 Unicode 转义
- 文本字符排查
- Emoji 和扩展字符编码确认

## 发布注意

Raycast lint 会校验 `package.json` 中的 `author` 是否为真实存在的 Raycast 用户名。

当前项目已经填入一个可通过校验的占位值，用于保证本地开发链路可运行；如果后续需要上架 Raycast Store，应替换为你自己的账号用户名。
